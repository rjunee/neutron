## Planning decisions (2026-08-31, verified against the tree — do not re-derive)

- **Window at the runtime seam, not inside assistant-ui.** `vm.messages` flows `MountedConversationImpl` → `ConversationRuntimeHost` → `useChatRuntime`/`useChatAdapter` (`landing/chat-react/useNeutronChat.ts:165-172`) → `ThreadPrimitive.Messages` mounts one bubble per adapter message. Slicing the array handed to `ConversationRuntimeHost` bounds the DOM of EVERY surface (active AND the up-to-8 hidden keep-alive ones) without touching the library or the keep-alive cache. LANDED in cc5d1ce3: `TRANSCRIPT_WINDOW_MESSAGES = 100`, one exported constant, `ChatApp.tsx:2061`.
- **Anchor-by-id, not slice-by-count.** `olderAnchorId: string | null` per surface. `null` ⇒ pure trailing `slice(-N)` (arrivals slide the window; newest always mounted). After "Load older" the start is PINNED by message id so live arrivals GROW the rendered list — assistant-ui keys bubbles by INDEX, so a shifting front would re-point every mounted bubble. Landed.
- **Identity-preserving short-circuit is load-bearing.** When `messages.length <= N` the windowed array IS `hostVm.messages` (same reference): `useChatAdapter` memoizes on `vm.messages` identity (#354 notify-storm guard) and `__tests__/switch-render-cost.test.tsx` pins conversions=0 / exact per-switch renders. Landed.
- **Reset on the DEACTIVATION edge** (`active` true→false) via a bail-out-safe updater (`prev === null ? prev : null`) — hidden surfaces shrink back to trailing N, switch-INTO does zero extra work, no render scheduled when already trailing. Landed.
- **Scroll preservation on load-older** exactly as the card prescribes: capture viewport `scrollHeight`/`scrollTop` at click; restore `scrollTop += ΔscrollHeight` pre-paint in a `useLayoutEffect` keyed on the RUNTIME's rendered message count (the extension lands one commit after the click). Landed.
- **Verified absent, stated in the record instead of built:** no deep-link/scroll-to-message path and no in-page transcript search exist in `landing/chat-react/` (grep `scrollIntoView|getElementById|location.hash` → only `main.tsx:256`'s root lookup). Card criteria 4 and 5 have nothing to regress.
- **Deliberately omitted:** IntersectionObserver auto-extend (card allows omission; the explicit control is the requirement and carries less scroll-anchor risk); any virtualization library; `MAX_MOUNTED_CONVERSATIONS` untouched. Revisit only after the owner re-measures.
- **CORRECTION to the previous plan's T2 (2026-08-31, this round):** branches NEVER edit `docs/AS_BUILT.md`. The 2026-08-18 decision (recorded in `docs/AS_BUILT.md` staging machinery and `.trident/as-built/trident/as-built-conflicts-killed-at-the-ro.md`) gives the log ONE writer: a branch stages exactly one entry at `.trident/as-built/<branch>.md` and the outer loop folds it into the canonical log on main after merge. `scripts/ci/as-built-write-guard.sh` FAILS any PR whose diff names `docs/AS_BUILT.md`.
