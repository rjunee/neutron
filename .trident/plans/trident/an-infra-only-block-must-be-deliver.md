# IMPLEMENTATION_PLAN — an infra-only block is delivered as infrastructure, not as a rejection (T3 of the gh card)

Regenerated 2026-08-16 against main (4eb3adc). The card: a run blocked for an INFRASTRUCTURE reason (required check never ran, PR conflicting with base, credential blink) must not terminate wearing REQUEST_CHANGES clothes. Survey findings that shape this plan: the durable signal ALREADY reaches the terminal row — `code_trident_runs.inner_result` (kept on harvested failed rows; `saveIfActive` never overwrites it) carries the workflow's `blockKind`/`terminalCause`, and `trident/inner-loop.ts parseInnerResult` decodes it FAIL-CLOSED — but nothing downstream reads it: `trident/delivery.ts interpretFailure` classifies off `failure_reason` strings only (an infra cause containing the word "conflict" today misroutes to the merge-conflict class and falsely claims "two changes edited the same code"), and the board renders every terminal non-done run as red "Failed". No open PR exists for this card (checked `gh pr list` 2026-08-16).
