# IMPLEMENTATION_PLAN.md — docs-only cheap delta path for the gate

Card: "A docs-only change must not pay for a full build — give the gate a cheap delta path" (T1 classify / T2 cheap path / T3 auditable). Architecture decisions locked by the planner — do not re-derive:

- Classification is JS-side and path-based, never model judgment (matches the probe pattern in `trident/inner-workflow.mjs`: one verbatim git command, every judgement in JS).
- The classifier lives INLINE in `trident/inner-workflow.mjs` (the workflow has no module resolution; see `test-strategy.ts` docblock) and is tested by the source-extraction technique from `trident/__tests__/ci-gate.test.ts`.
- Conservative by construction: unknown/weird/unparseable path, empty diff, or failed probe ⇒ `full`. Allowlist: `*.md`/`*.markdown` (case-insensitive) anywhere, plus `.trident/plans/**`; hard denylist prefixes `migrations/` and `.github/` force `full` even for `.md`.
- The build agent may skip the expensive suite only on its OWN measured docs-only delta, but the JS gate independently re-classifies from the real diff and treats a disagreeing claim as a blocker — a false docs-only claim can never merge unverified code.
- The cheap path skips the cross-model peers + adversarial seat and the full suite, NOT the PR, the synthesis/severity/merge gates, or branch protection.
