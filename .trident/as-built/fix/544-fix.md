## Issue 544 — reap codex-review test fixtures

### What changed

The review test's primary `run()` fixture is now registered at creation (`trident/codex-review.test.ts:95`). A registered-only reaper removes those directories synchronously and tolerates cleanup failure so cleanup cannot replace the test result (`trident/codex-review.test.ts:39-52`). It runs after every test and again on normal process exit (`trident/codex-review.test.ts:54-55`).

The fixture path is returned to tests (`trident/codex-review.test.ts:85-95`), which lets the focused controls observe that it remains usable during its case and is gone before the next case (`trident/codex-review.test.ts:921-930`). The remaining controls count the exact `mkdtemp` name shape with a live positive control, prove registered fixtures net to zero, prove an unregistered neighbor survives, and prove the exit fallback is registered (`trident/codex-review.test.ts:933-961`).

The pre-change lifecycle surface was completely enumerated with `git grep -n -E "mkdtempSync|afterEach|fixtureDir|process.on\\('exit'" origin/main -- trident/codex-review.test.ts`. Its positive controls found the import and three allocations at lines 19, 76, 607, and 762; it found no per-case hook, fixture wrapper, or exit hook. The latter two allocations already had local cleanup, now at `trident/codex-review.test.ts:627-644` and `trident/codex-review.test.ts:782-860`; the primary allocation did not.

### Decisions

Cleanup tracks paths created by this process rather than matching a shared-directory glob. The unregistered-neighbor control makes that ownership boundary executable (`trident/codex-review.test.ts:947-956`). Cleanup remains outside `run()` because callers can inspect the returned fixture until their case ends (`trident/codex-review.test.ts:921-925`).

No new runtime outcome, error, verdict, or refusal was added; this changes test-fixture lifecycle only. The invariant is maintained continuously by the per-case hook, with a synchronous normal-exit fallback that does not depend on a failing test body reaching teardown code (`trident/codex-review.test.ts:44-55`).
