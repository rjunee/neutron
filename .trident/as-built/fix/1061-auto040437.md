## Issue #1061 — Offline driver coverage for repeated findings and resumed fixes

### What changed

The literal worker fixture can now preserve one finding identity across rounds (`open/__tests__/project-build-e2e.test.ts:172-174`, `open/__tests__/project-build-e2e.test.ts:213-218`). The new G070 case drives two review rounds, asserts the existing review-arbitration stop, proves only one fix ran, checks the rejected checkpoint, and leaves the fake PR open (`open/__tests__/project-build-e2e.test.ts:932-945`).

The restart fixture now exposes its migrated database so a test can model a changed review budget between processes (`open/__tests__/project-build-e2e.test.ts:553`). The resumed-rejection case creates a durable rejected checkpoint, raises the stored cap, reconstructs the input row, and proves the next process dispatches `fix:1` before review and merges that fix (`open/__tests__/project-build-e2e.test.ts:1027-1048`).

The harness limitation inventory now names G070 and rejected-checkpoint resume as covered while retaining the remaining gaps (`open/__tests__/project-build-e2e.test.ts:1110-1119`).

### Decisions

Only harness behavior changed. The two production paths already exist: G070 returns the established `blocked` outcome and review-arbitration message (`trident/gates/review-progress.ts:15-18`), while a rejected resume enters the established fix worker path (`trident/build-run.ts:463-473`). The tests join those existing vocabularies rather than adding an outcome or a second path.

The G070 fixture uses two blockers followed by one blocker so blocker count improves while one identity repeats. That isolates the repeated-finding guard from the separate no-progress guard at `trident/gates/review-progress.ts:19-22`.

The resume fixture first stops at the configured ceiling, then updates the durable run cap before constructing process two (`open/__tests__/project-build-e2e.test.ts:1028-1040`). This produces a real rejected checkpoint without leaving a pending worker and makes `resumeFix` reachable.

Changed tracked paths were enumerated after staging with `git diff --cached --name-only`: `open/__tests__/project-build-e2e.test.ts` and this record.
