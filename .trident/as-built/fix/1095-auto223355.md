### Decisions

The baseline is evidence, not merely detector initialization. Waiting for one real screen closes the race where attachment succeeds but polling immediately discovers disappearance. The negative path uses the existing close-and-clear unwind because publishing a blind wrapper would keep the dead session in the pool, while leaving the verified pane alive would permit a second transcript owner.

Pane loss and composition expiry are new typed outcomes rather than message-only variants. This preserves the existing classification mechanism and keeps `unknown`, refusal, positive disappearance, deadline, and cancellation in separate branches.

The fresh-pane retry is limited to one attempt. A positive disappearance says the prior container is gone and the pool exit path is evicting it; other retryable classes do not establish that a fresh pane is the correct immediate remedy.
