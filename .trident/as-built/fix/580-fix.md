## Issue 580 — web persona editor

### What changed

The web Settings surface now mounts an owner-wide three-file markdown editor at
`landing/chat-react/SettingsTab.tsx:803-805`. The editor enumerates the fixed
allow-list from `landing/chat-react/personality-client.ts:1-3`, loads each file,
and saves the exact textarea draft with the loaded mtime through the existing
gateway contract at `landing/chat-react/personality-client.ts:23-35`. The UI
shows load/save failures, success, and an explicit reload-or-overwrite choice
for optimistic-concurrency conflicts at
`landing/chat-react/PersonalityEditor.tsx:28-53`.

The editor styling is part of the existing Settings vocabulary at
`landing/chat-react.html:1777-1782`. No second route or storage implementation
was added: web and mobile both write `/api/app/persona/file` with `content` and
`expected_mtime`; the mobile precedent is
`app/lib/admin-personality-client.ts:122-139`.

### Ownership decision

This is an owner-wide control placed in web Settings, beside the install-wide
model controls already described at `landing/chat-react/SettingsTab.tsx:1085-1101`.
`docs/SYSTEM-OVERVIEW.md:7323-7330` now owns the distinction between the three
files under `persona/` and root `USER.md`. The former are assembled into the
base-persona input by the live caller at
`gateway/wiring/build-live-agent-turn.ts:2108-2115`; root `USER.md` belongs to
the later context-file layer at `runtime/system-prompt.ts:52-65,142-148`.

The new client error joins the editor's existing load/save outcome vocabulary.
`mtime_conflict` with HTTP 409 gets the explicit conflict controls; every other
error defaults to the visible error message at
`landing/chat-react/PersonalityEditor.tsx:34-37,50-53`. This is fail-closed:
an unclassified response does not enable overwrite.

### Deliberately not changed

The gateway routes, mobile editor, and storage format were not changed because
the existing API already supplies the required shared write path. The web pane
does not edit root `USER.md`, because that file is a separate later context
layer documented above. No feature flag or alternate implementation was added.
