## Issue 1060 — reap retained project-build state

### What changed

The per-run project-build directory is created at `open/wiring/project-build.ts:200-201`. A new age-based reaper at `open/wiring/project-build-state-reaper.ts:14-43` enumerates the state root and removes a directory only when its decoded run id resolves to a terminal row whose `last_advanced_at` is at least seven days old. The retention constants are at `open/wiring/project-build-state-reaper.ts:6-7`.

The Open composer now has one shared project-build state root at `open/composer.ts:4342`, passes it into project-build preparation at `open/composer.ts:1194`, and runs the reaper immediately at boot and hourly thereafter at `open/composer.ts:4343-4355`. The supervised loop is registered before it starts and its quiescing stop joins the existing shutdown cleanup list at `open/composer.ts:4353-4355`.

### Decisions and defaults

Seven days is long enough to retain recent failure evidence while bounding the transcript growth by age, which is the requested retention dimension. An hourly cadence limits expiry lag without making directory scans frequent. The loop starts with an immediate sweep so a restart does not defer cleanup by an hour.

The existing outcome vocabulary is `TERMINAL_PHASES` plus `isTerminalPhase` at `trident/state-machine.ts:47-52`. The reaper uses that classifier at `open/wiring/project-build-state-reaper.ts:37`; every live phase, missing row, malformed encoded name, and unreadable timestamp is retained by default at `open/wiring/project-build-state-reaper.ts:32-39`. Thus an unknown answer never shares the deletion branch with a positive terminal answer.

The continuously maintaining mechanism is the composer-owned supervised loop at `open/composer.ts:4343-4355`. It reads durable run rows through `TridentRunStore.get`, whose database lookup is at `trident/store.ts:1034-1040`, so cleanup does not depend on the completed worker process remaining alive.

The production loop inventory was enumerated through the real Open composition boundary by `open/__tests__/loop-inventory-open-composer.test.ts:157-184`; its exact expected set now includes the reaper at `open/__tests__/loop-inventory-open-composer.test.ts:63-66`.
