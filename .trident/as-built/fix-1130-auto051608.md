## 2026-09-17 — Make table-ownership scanning safe against concurrent probe cleanup

### Change and evidence

`collectSourceFiles` snapshots candidate source paths at
`migrations/__tests__/table-ownership-conformance.test.ts:59-80`. The ownership
tests subsequently read each candidate through `findWriters` at
`migrations/__tests__/table-ownership-conformance.test.ts:166-175`. A candidate
that disappears in that interval cannot write a table, so `readSourceFile` now
returns `undefined` only for `ENOENT` at
`migrations/__tests__/table-ownership-conformance.test.ts:157-164`; all other
read failures still throw.

The regression creates, enumerates, and removes a root-source probe at
`migrations/__tests__/table-ownership-conformance.test.ts:234-249`. It asserts
both that the vanished probe reads as `undefined` and that a persistent approved
`projects` writer remains detected. The table verdict continues to calculate
both unapproved and stale writers at
`migrations/__tests__/table-ownership-conformance.test.ts:268-286`.

The seam probe remains in `gateway/`: its dependency-cruiser invocation takes a
root-relative path and executes with the repository root as its current working
directory at `gbrain-memory/__tests__/memory-swap-seam.depcruise.test.ts:82-108`,
then asserts the probe's root-relative source path at :128-147. Moving it into a
test directory would make the ownership scanner exclude it by the established
walk rule at `migrations/__tests__/table-ownership-conformance.test.ts:64-76`.

### Tests and mutation evidence

Before the change, starting the ownership test while the actual seam PASS probe
existed reproduced `ENOENT` after probe cleanup: the ownership run reported 8
pass / 7 fail. After the change, the same probe-coordinated run reported 16 pass
/ 0 fail for ownership. The seam test itself had unrelated dependency-cruiser
failures in this environment and is outside this change's scope.

### Scope and decisions

No `SPEC.md` decision changed. This change adds no feature flag or alternate
scanner: it replaces the direct read in the sole ownership scan. It deliberately
does not alter the seam test, dependency-cruiser configuration, unrelated seam
failures, or the full-suite gate.
