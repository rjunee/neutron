## Issue #1142 — retry a run on its own published PR

### What changed

Publication now records separately durable PR provenance (`migrations/0153_trident_published_pr_provenance.sql:1`, `trident/production-host-effects.ts:381-390`). The ordinary `pr` field remains an observation that launch preparation may populate, while `published_pr` is written only after publication witnesses an open PR on the reviewed head (`trident/production-host-effects.ts:388-389`).

Board dispatch carries that provenance only from the exact terminal run linked by the card (`trident/board-dispatch.ts:1512-1519`). Project composition supplies the carried value as fresh-admission ownership (`trident/project-build-host.ts:104-110`). Fresh admission continues only when the measured PR number, open state, and head all match; every foreign, closed, or moved PR retains the existing refusal (`trident/build-run.ts:261-265`).

The bidirectional tests prove publication persistence, owned retry, foreign refusal, and the specific filed regression where an observed PR has no provenance (`trident/production-host-effects.test.ts:228-233`, `trident/build-run.test.ts:224-249`, `trident/board-dispatch.test.ts:2020-2028`).

### Decisions

This uses reclaim semantics rather than `bound_pr`: the retry remains a build capable of planning, building, reviewing, publishing, and merging. It adds no feature switch or parallel execution path.

The durable invariant is that PR ownership cannot be inferred from observation. Publication maintains provenance independently of the failed run at `trident/production-host-effects.ts:388-389`; the database migration keeps it after process failure at `migrations/0153_trident_published_pr_provenance.sql:1`; exact-link dispatch carries it at `trident/board-dispatch.ts:1516-1519`. Discovery writes only the ordinary `pr`, so it cannot manufacture provenance.

The outcome remains in the existing `BuildRunOutcome` vocabulary as `blocked`; inability to measure remains `unknown`. A foreign PR therefore defaults to the same orchestrator-addressed refusal as before (`trident/build-run.ts:261-265`).

The filed citation `trident/build-run.ts:247` was correct for the issue's filing revision. On current main the refusal was at line 260; after this change it is at `trident/build-run.ts:265`. No other filed line citation required correction.
