### Decisions and continuous enforcement

The user resolved repo selection and canonical location; SPEC.md records the dated
product decision and the spec item records model acceptance. A missing declaration
is represented as legacy declaration data and goes through the same resolver. This
keeps existing projects working without moving directories. The default for a
nonempty declaration must name a member; no arbitrary first-repo fallback exists.

Every resolution validates the current declaration before returning a path
(`trident/project-repos.ts:61`). Thus an external editor cannot bypass validation
on the next dispatch, and the mechanism does not rely on the writer remaining
alive. The production test verifies the path persisted at admission
(`trident/board-dispatch.test.ts:2225`).

It found the stale merge comment and undecided location sentence; both were
