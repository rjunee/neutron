## Issue 1153 — distinguish suite report states and trust host-owned scope

### What changed

- `trident/gates/review-suite.ts:30-34` factors the existing `failed-preexisting` evidence classification into one helper. `:46-49` now treats a missing exit code on a `subset` scope as expected from host-owned scope, independent of worker `suiteOutcome`; an evidenced `failed-preexisting` claim uses that helper so its advisory evidence reaches the review task.
- `trident/gates/review-suite.ts:50-55` keeps the prior branch work: a null full-suite report has the no-command diagnostic, while a present full-suite report without an integer exit code remains unreadable and terminal `unknown`.
- `open/wiring/project-build.ts:461-467` establishes the two source facts: failure to derive a command returns `report: null`, while an executed command with timeout or unavailable log omits the exit code from a present report.
- `trident/gates/review-suite.test.ts:6-30` covers host scope over deferred, absent, and unexpected worker outcomes; it carries an evidenced `failed-preexisting` claim as advisory and keeps a full-suite missing receipt unknown. `open/__tests__/project-build-wiring.test.ts:148-164` verifies the intermediate host reader preserves that claim and evidence without running the full suite.

### Decision

`report === null` remains terminal `unknown` for a full-suite scope because `trident/gates/review-suite.ts:50` has no host receipt. A deferred subset's scope is set by the host at `open/wiring/project-build.ts:432-433`, and the host deliberately omits the exit code at `:457-460`; `trident/gates/review-suite.ts:46-49` therefore cannot rely on a worker spelling to decide the exemption. An evidenced `failed-preexisting` claim reuses the existing advisory vocabulary at `trident/gates/review-suite.ts:30-34`, which `trident/build-run.ts:565-570` passes into the terminal review task without granting approval; `applyReviewSuite` still only propagates blockers or preserves the panel result at `trident/gates/review-suite.ts:61-67`.
