# AGENTS.md — logger

`@neutronai/logger` is the repo's ONE leveled key=value logger (refactor O1). `createLogger(subsystem)` emits `[subsystem] event=<event> k=v` lines (the `LOG_TAG event=… k=v` convention from chat-bridge/reminder-outbound), gated by `NEUTRON_LOG_LEVEL` (`error|warn|info|debug`, default `info`, re-read on every emit). Values with whitespace/quotes/`=`/backslashes/control chars are logfmt-quoted with backslash escapes so lines stay single-line and whitespace-splittable. Suppression helpers generalize three existing hand-rolled patterns: `once(key)` (the GBrain `latchIfUnavailable` process latch — one line per key until `clearOnce` re-arms it), `clearOnce(key)` (the rate-limit-banner edge-triggered latch's falling edge — rising edge fires `once`, falling edge re-arms), and `rateLimited(key, ms)` (the wedge-alert `alertDedupeMs` cooldown — a throttle for a line that must keep appearing without flooding). `rateLimited` is close to the wedge-alert original but deliberately not bit-for-bit. The two consequences a caller has to plan around — **a clock reading behind the last stamp emits rather than suppressing** (a backward step of the non-monotonic wall clock, once it lands behind that stamp), and **the bound is on ATTEMPTS, not on delivered lines** — are stated once, with their reasons, in the `logger/index.ts` head docblock; this file does not restate them, because the same claim in three files is three times the drift surface and that is how the last three rounds each shipped a false one. **`logger/__tests__/logger.test.ts` is the specification of what these actually do — read the cases, not a prose restatement of them.** Latch state is per-process module state keyed `subsystem × key`, shared across logger instances. Sink and clock are injectable (`LoggerOptions.sink` / `.now`) for tests and DI seams.

This package is a `contracts`-band LEAF: it must import NOTHING from the workspace (dependency-cruiser enforces it). Broad `console.*` call-site adoption is still O2. F3, however, ALREADY imports this package from production host code: `logger/fire-and-forget.ts` exports `fireAndForget` / `neutralizeAbandonedSettle` (fire-and-forget rejection visibility) + `installProcessSafetyNet` (the process-level unhandledRejection/uncaughtException net), and host packages import them (e.g. `gateway/index.ts`, every standalone entrypoint, ~18 workspace packages). Allowed dependency direction: host code MAY import `@neutronai/logger` (a contracts-band leaf); the leaf still imports nothing back. Bundled Cores + the `loop` leaf must NOT import it (see the F3 gate exclusions + the `cores-use-sdk-only` dependency-cruiser rule).
