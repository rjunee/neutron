# Any tier in either cross-model review seat

The two owner-facing cross-model seats now declare every executor family as legal, including `claude`, while preserving `none` as a deliberate empty seat (`trident/phase-models.ts:231`, `trident/phase-models.ts:253`). The workflow mirrors those declarations in its role routes and resolves an explicit Claude choice into the standard reviewer prompt, `VERDICT_SCHEMA`, and `withModel` agent dispatch (`trident/inner-workflow.mjs:3132`).

CLI availability remains specific to the selected CLI route. Claude routes require no external credential, while unavailable Codex or Kimi routes are not dispatched and never substitute a Claude reviewer (`trident/inner-workflow.mjs:3137`). The existing no-silent-fallback invariant remains unchanged (`trident/kimi-review.ts:40`). Each CLI seat resolves its own model environment and uses a seat-specific output path, preventing cross-slot model drift and concurrent-file collisions (`trident/inner-workflow.mjs:3143`, `trident/inner-workflow.mjs:2999`). Deferred retries use the selected route's own prompt, schema, model application, and status field (`trident/inner-workflow.mjs:3215`).

Same-family selected sets, including the build seat, remain valid and emit `trident.panel-single-family WARNING` rather than being rejected; credential availability does not redefine what the owner selected (`trident/inner-workflow.mjs:3186`). The web settings pane explains that choice and derives its options from the server-supplied phase groups (`landing/chat-react/SettingsTab.tsx:1090`, `landing/chat-react/SettingsTab.tsx:1126`). The app uses the same server-supplied phase vocabulary, so the newly declared groups become selectable there without a parallel hard-coded allowlist (`app/app/codegen.tsx:8`). Effort remains disabled for CLI tiers but is selectable and applied when either generic seat holds a Claude tier (`trident/phase-models.ts:409`, `trident/inner-workflow.mjs:3149`).

Regression coverage runs the production launcher into the real workflow and pins GPT build plus Opus review-seat dispatch, unavailable-CLI non-fallback, same-family warning behavior, phase-group agreement, and both settings clients (`trident/__tests__/cross-model-dispatch.test.ts`, `trident/__tests__/phase-model-coverage.test.ts`, `landing/chat-react/__tests__/codegen-settings-web.test.tsx`, `app/__tests__/codegen-settings-reachable.test.tsx`).
