## 2026-09-25 — Retain host-suite lane logs after a failed run

Issue #1298's audit found a red 1,687-file host run whose terminal transcript was truncated before the failing case. The runner then deleted its per-lane logs unconditionally, so that run could not identify the failing lane from its receipt. This change addresses diagnostic loss, not test execution time; it makes no wall-clock saving claim.

`scripts/run-tests.sh` continues to create one private temporary directory per invocation. Once lane logs exist, a nonzero exit retains that run's chunk and lane logs and prints their location. A zero exit removes the directory as before. Only failures after all lanes settle carry a marker; the runner retains at most three such directories under the same temporary parent. A signal-interrupted run stays unmarked because a background chunk may still be writing; another run never prunes it. This is deliberately not a global disk cap: interrupted-run directories require operator cleanup after diagnosis. The current failure remains available. Refusals before the directory exists have no lane logs to retain. Test discovery, assignment, retry policy, coverage accounting, and host receipt semantics are unchanged.

Focused verification on the implementation worktree:

- `bash -n scripts/run-tests.sh` and `git diff --check` passed.
- `bunx eslint scripts/run-tests-selftest.test.ts`, `bunx tsc --noEmit -p tsconfig.json`, and `bunx tsc --noEmit -p trident/tsconfig.json` exited zero.
- `bun test scripts/run-tests-selftest.test.ts scripts/__tests__/run-tests-http-lane.test.ts` passed with host listener access: 40 tests, 220 assertions, zero failures. A red fake-Bun lane retained its known `chunk-000.log` in a mode-0700 directory and stayed red. An early coverage-hole refusal retained its existing chunk log. A green sibling left its fixture-owned temporary parent empty. Four red runs under one parent retained only three settled directories while an unmarked active sibling remained untouched. A TERM-interrupted parallel run retained its chunk log without a marker while the fake writer was still live, and four later settled failures did not prune it. The fake runner tests now scope `TMPDIR` to their fixture so their intentionally red cases do not leave host-wide receipts.
- Semantic mutation deleting logs on exit 1 made both red and early-refusal controls fail (2 failed tests). Semantic mutation retaining logs on exit 0 made the green cleanup control fail (1 failed test). Raising the retention cap from 3 to 999 made the bounded-retention control fail with four marked directories. Reversing the settled-lane marker guard made the TERM/live-writer control fail (1 failed test). All mutations were removed and the focused command passed on restored source.
