## 2026-09-25 — Refuse unbindable host suites early and narrow PGLite lane retry

The #1298 audit measured 1,673 discovered and executed files in one green host run. Its 19 Bun process durations summed to 1,827.00 seconds, which is process time rather than elapsed wall time. The runner previously loaded every test file for Bun discovery before finding out that the host could not bind a listener, and retried the whole PGLite lane after any nonzero exit. Those are the baseline defects addressed here; this change has no paired full-suite timing measurement and claims no measured wall-time saving.

`scripts/run-tests.sh` now asks Bun to bind a real ephemeral `127.0.0.1` listener after cheap configuration and zero-file checks, before Bun's expensive discovery on a normal host suite invocation. The probe closes the listener before discovery begins. A bind error or a five-second in-process probe deadline refuses the run with exit 3 and the host error, before any test process starts. Synthetic roots and fake-Bun runner tests opt in explicitly; plan-only mode never probes. The denial seam is effective only when both a synthetic root and fake Bun are selected.

The PGLite lane now retries only when the failed attempt has exactly one Bun error line matching a recognized WASM initialization or boot signature, its final failure summary says `1 fail`, and no Bun test-timeout diagnostic appears (`scripts/run-tests.sh:696-713`). Bun may print a native thrown `TypeError:` or `Error:` without an `error:` prefix; both forms count toward the one-error limit. A timeout, additional error, multiple failures, missing summary, or unknown error stops after one attempt. Each attempt's complete output is emitted, the configured retry ceiling and serial/per-test settings are retained, and final lane coverage remains in the existing audit.

The real-HTTP lane previously matched direct `Bun.serve` and `await boot` calls in a test file, but missed `gateway/__tests__/sigterm-survivor.test.ts`: that test spawns a fixture whose own `boot({ port: 0 })` opens the listener. The test now carries a standalone `// @neutron-real-http` marker, and the lane classifier recognizes only that anchored comment form. A prose mention of the marker remains in the general lane. This is an explicit declaration for indirect listener ownership, not a new retry or a relaxation of coverage accounting.
