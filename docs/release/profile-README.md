# Ryan Junee

I'm an engineer-founder. I've had three exits: Omnisio to Google/YouTube, Ostro
to Veeva and Parsable to CAI Software. I was a product manager at YouTube and a
part-time partner at Y Combinator.

These days I build agent harnesses, the systems that turn coding agents into
reliable, always-on workers:

- **[Neutron](https://github.com/rjunee/neutron)** is a self-hosted harness. It
  runs a fleet of long-lived Claude Code sessions, one per project, with
  persistent memory, scheduled and autonomous work, and an autonomous
  build-review-merge pipeline. It's open source under Apache-2.0.
- **[Neutron Enterprise](https://github.com/rjunee/neutron-enterprise)** is
  Neutron for teams and operators.

I write about building these systems at [ryanjunee.com](https://ryanjunee.com),
and post at [x.com/ryanjunee](https://x.com/ryanjunee).
